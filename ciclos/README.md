# ciclos/

Um arquivo por ciclo Ox concluído: `Ox-dd-mm.md`.

Criado por `/winnet:fechar-ciclo`, **somente após aprovação explícita do LEO**.

## Conteúdo de cada registro

- Janela analisada e relatórios usados
- Decisões **aprovadas** pelo LEO
- Decisões **recusadas** e o motivo
- O que ficou pendente para o próximo ciclo
- Nota-resumo do ciclo
- Data do próximo monitoramento e da próxima Ox

O commit correspondente usa a mensagem `[Ox dd/mm] resumo do ciclo`. O histórico do git é o
registro oficial — cumpre o papel que o histórico de conversas cumpria no Project.
